# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please follow these steps:

1. **Do not create a public issue** on GitHub.
2. Report the vulnerability privately by opening a [Security Advisory](https://github.com/shditz/url-shortener/security/advisories/new) or contacting the maintainer directly.
3. Include as much detail as possible:
   - A description of the vulnerability.
   - Steps to reproduce or a Proof of Concept (PoC).
   - Potential impact of the issue.

We will review the report promptly and coordinate a fix and release. Thank you for helping keep this project secure!
